Bug: Popular card gradient invisible against page bg

AppColors.pinkBg = #FFF5FA = rgb(255, 245, 250). The page background is also pinkBg. So the popular card's gradient [pinkBg, cream] has an INVISIBLE left/top edge (top-left of the card is the same color as the page bg behind it).

The yearly card is solid cream. The popular card's bottom-right is also cream. The two cards visually merge into one big "right block". User sees: free on left + (popular+yearly) on right = 2 visible things. They report "i only see 2 col" and "3rd card missing".

1. CURRENT (deployed — commit 76fb815) — popular gradient [pinkBg, cream]

The popular card's left edge is invisible. The cream bottom-right blends into the yearly card.

    • Why this happens: Flutter's Container with a gradient and no color shows the gradient. The Border.all(width: 4, color: pink) should outline the card, but the page bg is the same color as the gradient's top-left, so the border's top-left corner visually disappears into the page bg. Combined with the yearly card's cream bg touching the popular card's cream end, they look like one big block.
    Proposed fix: Change one line in lib/screens/pricing_screen.dart:231-235: 
    // Before
const LinearGradient(
  colors: [AppColors.pinkBg, AppColors.cream],
  begin: Alignment.topLeft,
  end: Alignment.bottomRight,
)

// After
const LinearGradient(
  colors: [AppColors.pinkSoft, AppColors.cream],
  begin: Alignment.topLeft,
  end: Alignment.bottomRight,
)
    No data, l10n, or business logic change. Just the gradient colors.

    Alternatives I considered

    • Reverse gradient [cream, pinkBg] — still has the same problem on the bottom-left.
    • Vertical gradient [pinkSoft, white] — looks like a different style from the rest of the design system.
    • Solid pinkSoft bg — boring, loses the "premium" gradient feel.
    • Thicker border + drop shadow — would make the popular card stick out but doesn't fix the visual merge with yearly.
