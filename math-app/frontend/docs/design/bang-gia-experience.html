lib/widgets/kid_nav_bar.dart:9 — visible on every screen. "Bảng giá" is the conversion path (links to /pricing), so it's the primary CTA pill. "Chủ đề" and "Liên hệ" are quiet text links.

What the active state looks like in code

  • The "Bảng giá" pill gets a 2px white border when activeLabel == 'Bảng giá' (set by the pricing screen's KidNavBar)
  • The "Chủ đề" text link gets a soft-pink pinkSoft pill background + small dot when activeLabel == 'Chủ đề' (set by the home screen)
  • The "Liên hệ" link opens Facebook in a new tab (external URL, no active state)
