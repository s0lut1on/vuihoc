# HocVui — Feature Roadmap Suggestions

> Generated 2026-09-11. Prioritized by impact vs effort for Vietnamese kids math market (ages 5-7).

---

## Growth Drivers (Traffic + Viral)

### 1. Referral Program — "Mời bạn bè, tặng 1 tháng Premium"
- Each user gets unique link `sekklings.com/r/MABC123`
- Referrer gets 1 month premium free when friend signs up
- Built with existing auth + payment infra
- Biggest lever for organic growth in VN (Zalo sharing is huge)
- **Effort:** 3-5 days
- **Impact:** High — compounds organic acquisition

### 2. Shareable Achievement Cards
- Kid completes lesson → generate colorful card with score + mascot
- One-tap share to Zalo/Facebook
- Card has app link + "Học thử miễn phí"
- Viral loop: parent shares proudly → other parents see → sign up
- **Effort:** 2-3 days
- **Impact:** High — fastest viral loop, leverages VN sharing culture

### 3. Teacher/Class Mode
- Teacher creates class, shares code, kids join
- Teacher assigns topics, sees class progress
- Free for teachers → schools push adoption
- One teacher = 30+ kids onboarded
- **Effort:** 1-2 weeks
- **Impact:** High volume but longer sales cycle

---

## Engagement (Retention)

### 4. Avatar Customization
- Kids earn coins from lessons, buy hats/accessories for mascot
- Strong daily return motivator for 5-7 age group
- Existing mascot system already in place
- Coins = lessons completed (already tracked in progress)
- **Effort:** 3-5 days
- **Impact:** Medium-high — daily return habit for kids

### 5. Badge/Achievement System
- "100 bài đúng liên tiếp", "7 ngày liên tục", "Master phép cộng"
- Visual badge wall kids can see
- Parents see badges in dashboard
- Push notification when new badge earned (notification service exists)
- **Effort:** 3-5 days
- **Impact:** Medium-high — gamification drives retention

### 6. Daily Challenge Mode
- 5 mixed problems, timed, leaderboard ranking
- Uses existing leaderboard (already has 50 fake users)
- Kids compete daily → daily return habit
- Top 10 get "Vô địch tuần" badge
- **Effort:** 2-3 days
- **Impact:** Medium — leverages existing leaderboard infra

---

## Content (SEO + Value)

### 7. Printable Worksheets (PDF)
- Each lesson topic has downloadable PDF worksheet
- Parents print for offline practice
- Huge SEO win: "phép cộng lớp 1 bài tập PDF" searches
- Each worksheet page = indexable content for Google
- **Effort:** 1-2 days
- **Impact:** High — drives search traffic, printable = tangible value

### 8. Short Animated Video Explainers
- 30-60 second animation per topic (addition, subtraction, etc.)
- Pre-readers can watch before doing exercises
- Embed in lesson page = more indexable content
- YouTube versions → another traffic source
- **Effort:** 1-2 weeks (needs animation assets)
- **Impact:** High long-term — YouTube + SEO dual channel

### 9. Parent Blog / Articles
- "Làm sao giúp bé học toán lớp 1", "5 trò chơi toán cùng con"
- Weekly article, SEO-optimized for Vietnamese search queries
- Marketing site already has blog infrastructure
- Content marketing = long-term organic traffic
- **Effort:** Ongoing (1 article/week)
- **Impact:** High long-term — sustainable search traffic

## Recommended Build Order

Build these 3 first to create a growth flywheel:

```
Worksheets (SEO traffic)
    → Kids use app (engagement)
    → Parents share achievements (viral)
    → Friends sign up via referral (compounding)
```

1. **Shareable achievement cards** — fastest viral loop
2. **Printable worksheets** — SEO content Google can index
3. **Referral program** — compounds with #1, each new user brings more

These three create a self-reinforcing growth engine:
- Worksheets bring search traffic
- Kids use app and earn achievements
- Parents share achievements on Zalo/Facebook
- Friends sign up via referral links
- New users repeat the cycle
